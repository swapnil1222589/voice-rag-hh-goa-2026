System Architecture

Voice-enabled RAG pipeline with hybrid retrieval and multilingual guardrails

🎤

Voice Input

Browser MediaRecorder API captures audio in WebM/Opus format

↓
🔊

Speech-to-Text

ElevenLabs Scribe (default) or Sarvam Aasaar

Audio normalised to 16 kHz WAV before API call. Supports 14 Indic languages + English

ElevenLabs Scribe v1 Sarvam Aasaar librosa 16kHz normalisation
↓
🛡️

Input Guardrail

Validates the transcribed query before retrieval

  • Length constraints (min/max chars)
  • Unsafe/harmful content (7 regex patterns)
  • Prompt injection detection (5 patterns)
  • PII detection (email, phone, SSN, card)
  • Gibberish detection (STT noise filter)
↓
🔍

Hybrid Retrieval

Two retrievers fused via Reciprocal Rank Fusion (RRF, k=60)

Dense (Vector)

ChromaDB HNSW + paraphrase-multilingual-MiniLM-L12-v2

Top-15 candidates

+
Sparse (BM25)

BM25Okapi with Unicode-aware tokenizer (handles Indic scripts)

Top-15 candidates

ChromaDB HNSW (cosine) rank-bm25 RRF fusion Batch cosine reranking
↓
⚖️

Relevance Guardrail

Checks if retrieved context is relevant enough

Threshold: RRF score ≥ 0.25. If no context → abstain without calling LLM

↓
✨

Grounded Generation

OpenAI GPT-4o-mini answers only from retrieved context

System prompt explicitly forbids hallucination. Abstains if context is insufficient.

GPT-4o-mini Context-only prompt Tenacity retries
↓
🔬

Output Guardrail

Verifies the generated answer is grounded in retrieved context

  • Extracts factual claims (numbers, dates, years)
  • Checks each claim appears in retrieved context
  • Detects correct refusals as positive outcomes
  • Computes grounding confidence score
↓
💬

Final Answer

Structured response with answer, sources, confidence, and per-stage latency

Chunking Strategies

📐

Fixed-Size

Token-window with overlap. Baseline comparison. tiktoken cl100k_base.

🌿

Recursive

Splits on sentence boundaries first, then words. Preserves sentence integrity. Indic danda (।) aware.

🧠

Semantic ★

Groups sentences by Jaccard similarity. Breaks at topical boundaries. Default strategy.

🏷️

Metadata-Aware

One chunk per passage, all metadata preserved. No splitting. Ideal for short passages.
